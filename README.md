# E-Cart Redux

Build project using vite npm

remove unwanted component
- create structure for project using components
- install libraries for styling react bootstrap
 & 
 bootswatch free theme library
- install react router dom to enable routing
- install Redux Library
- create store for products
- provide store to the app using Provider
- create store using configure store method
- create slice using createSlice method to handle reducers and actions
- create an api call using createAsyncThunk and use extrareducers to handle promise 
- to add products to wishlist create wishlist slice to define actions and reducers
- create cart slice to add products to cart
- store products in localStorage to get a single product in view page
- Hooks Used :
-> useState- to hold state
-> useEffect- to handle side effects and render
-> useParams- to get path related items
-> useDispatch- to dispatch actions
-> useSelector- to select state from store for components
-> useNavigate- navigate to components

- install sweetalert2 to add customized alerts
